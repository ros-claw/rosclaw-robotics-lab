# Luna 视觉导航本地交接

代码位于 `/data/rosclaw/robotics_lab/rosclaw-robotics-lab` 的 `luna-nav-20261121` 分支。[README](README.md) 记录启动、抓帧、控制测试和停止。一次 stop 后再 start 会创建新世界和新运行 ID。

| 阶段 | 已有证据 | 待验收 |
|---|---|---|
| P0 | Isaac 6.2、Humble Nav2、时钟、TF、点云、扫描、正常停止及超时清理 | — |
| P1 | RGB-D、标定、采集时刻 TF、哈希和 10 个标靶测量 | 运行中暂停/reset、定位注入和动态外参定量检查 |
| P2 | 单分叉灰盒、地图和换牌导出。公开清单与地图逐字节一致。禁止门区回归测试通过 | 在线候选投影、执行中通道约束、L1/L3 和验收种子 |
| P3 | 受保护速度链、完整物理过门与到达、取消和停车复核 | 连续改路和 ROSClaw 会话 |
| P4 | 真实 Luna 接入，换牌后选择及实际过门均改变 | 终点标识换位和活动路径上的旧答复故障注入 |
| P5 | 模型输入、事件、路径与 PhysX 离线交互回放，含过期拒绝和超时 | 实时四态和断流状态 |
| P6 | 独立 Isaac 展示相机，三条 1× 录像和字幕，实测帧率与 RTF | 跟随镜头、美术和 30 fps 性能目标 |
| P7 | 小闭环独立评估与本地交接 | 预登记六集验收和完整故障矩阵 |

原始记录位于工作区的 p0-evidence 和 p2-evidence。各试次保留 manifest、JSON、JSONL 与原始日志。已验证官方模型网关。换牌对照、实际图像和响应见 [P4 报告](P4_REPORT.md)。

早期 DWB 和 MPPI 失败日志已保留。地面碰撞修正以后，MPPI 实际通过了右门与左门。完整试次索引为工作区的 `attempts.jsonl`，通过的语义成对证据为 `p4-live-evidence/live-pair.json`。
