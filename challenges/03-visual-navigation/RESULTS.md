# Luna 单分叉实际运行结果

单分叉采用 Isaac Sim 6.2、Nova Carter、Humble Nav2 MPPI 和官方 Responses API `gpt-6-luna`。两个场景使用相同的地图、规划参数和公开中性候选，交换蓝色 B 与橙色 A 的标牌位置。任务始终要求通过蓝色 B 对应的通道。模型收到实际车载 PNG。独立 PhysX 评估离线复验执行路线和低速驻留。

| 录制试次 | 结果 | 终点误差 | 独立物理证据 |
| --- | --- | --- | --- |
| 20261121T065948Z-a38ea9a2 | Luna 选择右侧 c24，实际通过 c24 | 0.172 m | 平面行程 11.64 m，驻留峰值 0.0084 m/s，非地面接触 0 |
| 20261121T070119Z-9b0c72bd | Luna 选择左侧 c71，实际通过 c71 | 0.209 m | 平面行程 11.56 m，驻留峰值 0.0043 m/s，非地面接触 0 |
| 20261121T070248Z-949da2e7 | 50 ms API 时限触发真实传输超时 | — | 无控制请求，超时后 4.00 墙钟秒内平面速度峰值 0.00082 m/s |

原始运行目录在工作区 `p4-live-evidence` 的 `videos-original`、`videos-swapped` 和 `videos-timeout` 下。每个目录保存启动清单、模型帧及哈希、原始响应或传输错误、ROS 日志、PhysX 轨迹与接触、独立展示相机原始帧和时间索引。生成、编码和复核命令见 [README](README.md)。

两个正常录制试次各有独立带字幕 MP4 与同步交互回放。字幕按同次试验时间戳添加，整个片段从同一原始视频以 1× 墙钟速度导出，无剪接。原始视频分辨率为 896×504。两条正常路线各录得 719 帧和 680 帧，实际约 11.40 帧/秒和 11.14 帧/秒。编码 PTS 与墙钟帧索引最大偏差小于 1 ms。录制时，五秒窗口 RTF 中位数为 0.963 和 0.956，p5 为 0.915 和 0.816。此前无录制试次的中位数为 1.107 和 1.081。采集低于 30 帧/秒目标，录制开销与换牌 p5 也未达到规格的实时展示门槛。

两种录像版语义对照由 `evaluator/live_pair.py` 复算并写入 `p4-live-evidence/recorded-live-pair.json`。超时独立证据为超时试次的 `timeout-evaluation.json`。录像与控制频率数据见 `p4-live-evidence/recording-metrics.json`。离线回放还覆盖模型等待、视觉结果、本地过期拒绝和请求超时。工作区 `attempts.jsonl` 保留早期底盘卡滞、TF 获取超时和视觉过期等失败。

本轮验证范围是单分叉。运行时换门、ROSClaw daemon 注册、终点标识互换、完整多场景与六集预登记验收仍见 [交接清单](HANDOFF.md)。


## 单通道连续改路追加验收

同一单分叉额外完成四次实车仿真，累计验证八次无驻留的路径交接。一组使用官方 Luna 看图确定 c71，另一组用固定 c24 控制指令。每次保持最初通道承诺，完成两次 FollowPath 预占式接续并忽略真实旧动作回执。延迟验证使用一条实际规划结果，测试程序控制其投递时机。两次取消试次都在完全通过选定门区后停车。正常的 Luna 试次录像和回放位于 `p3-continuous-evidence/luna-swapped/20261121T073007Z-99cf21d0`。独立评估汇总见 `p3-continuous-evidence/summary.json`。


## 动态遮挡触发同会话重新观察

试次 `20261121T105949Z-fd238476` 中，卷帘在仿真 7.02 秒开始打开，8.80 秒完全打开。第一次 API 使用 4.90 秒真实图像，Luna 返回 `reobserve`。第二次使用 10.80 秒新图像，实际返回 `select_candidate c71`。两张图像哈希与两条官方响应均可复验。第一次请求至 FollowPath 提交前，PhysX 平面速度峰值为 0.00082 m/s。此后车辆通过 c71、两次连续交接并在距终点 0.232 m 处停稳，非地面接触为零。

试次 `20261121T110142Z-63e1f4c2` 将预算限制为一次。首帧返回 `reobserve` 后进入 HOLD，没有提交导航动作。遮挡试次验证的是出发前的动态可见性，不覆盖行驶中突然横穿、封路后的重新换门和恢复。证据位于工作区 `p8-reobserve-evidence`。

## 行驶中封堵与自适应恢复

同一程序从当前 LaserScan、TF 和 Nav2 完整代价地图识别路径受阻。场景配方只改变 Isaac 中的障碍物位置，决定停车或恢复的控制逻辑只读取传感器、任务规则与运行期限。新地图持续显示受阻后先取消活动动作，再独立检查 PhysX 低速驻留。保留原通道时使用新观测和局部、全局地图重新验证。若任务明确允许替代，重新采集 RGB-D，再向 Luna 请求新候选。发起恢复运动前仍检查局部足迹与活动通道。

早期试次揭示两类恢复失败。暂时封堵解除后，滚动代价地图的旧障碍会妨碍 MPPI。恢复现在只在驻车后刷新该层，并要求扫描与两次完整滚动地图更新均已推进。持久封堵后直接切到相反方向曾因底盘仍朝向原通道而无法形成进展。换路现在可在已验证的空闲停靠范围内转向，确认低速和里程计位移，再根据修正后的地图姿态重新规划。所有失败与新试次证据都保存在工作区 `p9-adaptive-evidence`。

## 行驶中定期调用 Luna 与多障碍试次

Isaac 仓库中增加一块可升降挡板、两个沿墙移动的货箱和三个固定障碍。三件移动物体按各自的仿真时间表运动。运动调度不依赖模型。规划和视觉逻辑只读取相机、地图、任务规则与控制反馈。

通过试次 `20261121T191831Z-22da5f1f` 设置 5 墙钟秒的周期和 8 次复核预算。除首选与换门两次语义决策外，共发出 8 次行驶复核。PhysX 在 7 次调用窗口内记录到至少 5 个高于 0.05 m/s 的速度样本。请求间隔中位数为 5.37 s，响应中位数为 2.87 s。一次旧动作的回复在取消后返回并被丢弃。

首次有效的复核让沿路径的代价地图检查从 2.4 m 扩展到 4.8 m。仿真 16.62 秒时，常规范围内仍未发现封堵，扩大后的检查已从连续的地图样本确认挡板。系统取消现有动作，PhysX 验证停车，随后 Luna 根据新相机帧和任务允许的唯一替代选项提议 c24。车辆通过 c24 并在距终点 0.103 m 处停稳，非地面接触为零。完整录像、模型帧、响应和复核时间轴在工作区 `p10-live-vision-evidence/qualified-audit`。

早期两个试次分别记录了右侧货箱导致绕行净空不足，以及已返回的视觉建议未成功绑定活动动作身份的失败。前一试次保持停车，后一试次通过常规检测完成绕行。两个试次保留在同一证据根目录。实验验证的是单分叉仓库内的异步 API 复核，响应耗时按墙钟报告。

## API 耗时拆分和同场景提速

在同四张真实行驶画面上交替请求官方 API。原版使用全尺寸高清 PNG 和带证据框的契约，精简版使用 640×360 图和简短回复。原版连接建立约 0.49 s，精简版约 0.50 s。建连到收到完整回复的中位耗时由 2.44 s 降到 1.57 s。curl 的早期字节时间在该网络路径上接近建连时刻，因此这段耗时只能按上传、服务处理和响应传输的总和报告。请求体中位大小由 190,397 到 56,743 字节，输出中位 token 数由 115 到 58。四组配对的总耗时中位数从 2.94 s 降为 2.07 s。两版都要求复核左侧挡板，画面不可用时都要求重观。两张边缘物体图的建议不同。

同一六障碍配方、地图、录像模式和绕行规则下，普通档位以 `20261121T191831Z-22da5f1f` 为对照。提速档位 `20261121T193120Z-a53a6b29` 使用精简视觉复核和 0.65 m/s MPPI/平滑器上限。两个试次的活动段实时因子均约 0.91。首次视觉请求至 PhysX 验收用时从 88.19 s 降到 75.10 s。FollowPath 活动段由 65.95 s 降至 54.55 s。车身速度峰值为 0.41 m/s，最后仅通过 c24，误差 0.112 m。该试次封堵触发后的实测低速前位移为 0.044 m，非地面接触为零。此轮由扩大后的常规本地范围确认封堵，Luna 仍完成换路建议与行驶中复核。

3 秒调度复跑 `20261121T193352Z-fd9c1d0c` 也通过 c24 并停稳，终点误差 0.113 m，非地面接触为零。整趟墙钟为 78.14 s，实际复核间隔中位数为 4.66 s，API 中位响应 2.26 s。逐次启动 RGB-D 采集约需 1.2–1.4 s，调度值和实际请求间隔须分别观察。

所有调用和运动原始证据位于工作区 `p11-speed-evidence`。上述制动数据对应实测场景及触发时的速度。通道外推、实车速度与制动距离需要单独量测。

## 常驻 RGB-D 和更密的异步导航

在同一动态仓库和录像口径下，比较逐次启动 RGB-D 的试次 `20261121T193352Z-fd9c1d0c` 与常驻取帧试次 `20261121T195141Z-6be5663b`。两次均使用 0.65 m/s 的试验上限和精简视觉。常驻试次的 RGB-D 从请求到归档中位数由 1.229 s 降至 0.140 s，p95 由 1.326 s 降至 0.181 s。实际 API 请求间隔中位数由 4.655 s 降至 2.599 s，API 中位响应分别为 2.257 s 和 2.185 s。新的 16 次 API 调用互不重叠，每个调用窗口均有独立 PhysX 运动见证。整趟墙钟为 75.02 s，通过 c24，最终误差约 0.16 m，非地面接触为零。PhysX 底盘中心到经校验路径点的 p95 距离由 0.291 m 降到 0.255 m。

增密复核使两个试次将远处边缘货箱列为路线封堵。都在通过门前安全停车，随后因无授权剩余候选进入 HOLD。将提前复核收敛到路径核心后，近处的常规检查仍采用完整足迹。保留以上失败记录供对照。证据根目录为工作区 `p12-async-evidence`。

带录像的收敛复核试次 `20261121T195554Z-b41660c9` 正确绕行并停稳，全程无非地面接触。同场景试验了更陡的 MPPI 局部软代价衰减。活动段仿真用时为 48.52 s，与保守配置的 48.45 s 接近，PhysX 跟踪误差 p95 则从 0.255 m 到 0.294 m，因此交付继续使用通过对照的保守参数。

关闭独立展示相机录制后，收敛复核和保守档位的最终试次 `20261121T195745Z-14eef33a` 完成 c24 绕行，终点误差 0.190 m，非地面接触为零。活动段 5 秒窗口 RTF 中位 0.988、p05 0.922，实际复核请求间隔中位 2.59 s，整趟 73.41 s。带录像的常驻试次 RTF 中位为 0.887、p05 0.849。两组使用同一地图和障碍配方，分别覆盖取证负载下和关闭展示录像的运行条件。
