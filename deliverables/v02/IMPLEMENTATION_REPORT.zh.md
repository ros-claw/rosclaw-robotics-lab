# ROSClaw × Isaac Sim v0.2 实施与验收报告

更新日期：2026-10-09 UTC。依据本机真实运行证据、独立评价器、GitHub 合并状态与发行文件；第三方工程师实测尚未安排。

**冻结运行源码上的 16 次尝试中（含启动失败），14 次通过独立验收。** 每类至少五次独立 Native 测试，启动未完成另计；原定十五次与预先声明的一次标准追加测试合并展示。各类实际通过数见表，失败不会被成功样本替换。成功整圈中的 56 次到点记录最大位置误差为 0.151827 米。该工程回归支持在已配置仓库中运行受约束的自然语言任务，不能据此宣称生产级可靠性或比 Codex 更快开发机器人应用。

## 1. 实施范围与执行链路

DGX Spark GB10 / Ubuntu 24.04 ARM64 / Isaac Sim 6.1.0 / ROS 2 Jazzy / Nav2 1.3.13。官方在线仓库与 Nova Carter 保持复用；模型是实际配置的 `openai-codex/gpt-6.1-sol`。

一次自然语言输入 → Native Agent 观测并逐站提议 → Agentd/Operator/rosclawd 绑定 Body 并授权 SIM → Nav2 控制真实仿真机器人 → 独立 PhysX/LiDAR/接触评价 → ExecutionReceipt → 最终有序巡检验证、Practice/Memory 与 TaskKernel 关闭。

Agent 不直接发布轮速或调用整圈巡检脚本。工具只接受四个注册站点。每站要求 Nav2 成功、实际位置误差 ≤0.4 米、稳定停留 ≥2 仿真秒、新鲜有效 LiDAR、完整接触观察及零非地面碰撞。最后还需完整顺序和成功 Memory 收据；单站成功不代表整个任务完成。

当前 Runtime 使用 `enable_firewall=False`、SQLite Memory 和同 UID 开发进程边界；没有据此验证全部可选安全模块、生产权限隔离、seekdb 性能或真实硬件。

## 4. 现场故障补测

| 故障 | 实际条件与结果 |
|---|---|
| 超时 | 机器人先实际运动，期限触发失败；取消得到确认，独立速度证据确认停止 |
| 断线 | 实际断开观测通道；通过隔离 SIM 的 DDS 双服务器取消，另验物理停止 |
| 暂停 | 实际运动后 SIGSTOP 所属 Kit；仿真时间不推进；取消后恢复，连续推进的 PhysX 窗口确认停止 |
| Navigator-ABORT / 控制器仍活动 | 真实 Nav2 ABORT 6 与真实 FollowPath 活动态同时记录；实际取消 UUID 得到确认，独立物理停止通过 |

公开统一故障 CLI 的本轮重新运行结果及脚本 SHA 另列 `faults/public-wrapper-index.json`；未把它们计入 Native 整任务成功数。

暂停时初始 `physical_stop_verified=false` 保留。只有恢复后的独立窗口可证明停止。ABORT 使用明确的隔离 SIM 延迟代理触发真实 BT ACK 超时，不伪造状态、不直接发运动；这不证明默认 Nav2 必然遗留目标。第一次暂停验证窗口错误、第一次 UUID 日志序列化失败和一次 Nav2 启动失败均保留。故障测试总时长不等于停止延迟。详情见 `deliverables/v02/FAULT_TESTS.md`。

## 9. Challenge 02 与公平对照

已交付只读空间候选原型：实际 USD 货架包围盒、官方占据地图、实际新鲜 PhysX 位姿、Nav2 足迹/padding 与 Body 哈希绑定；筛除未知/占据/越界单元，验证保守净距、当前可达连通域和静态视线，生成面向目标的观察姿态。它不读四站配置，不增加写死的第五站，也没有运动权限。

实际物理货架实体分组后有 8 个开发实体和 5 个 holdout 实体；仅一个开发实体产生 3 个静态安全候选。9 项门槛回归通过。USD 语义是已知场景先验，不声称摄像头自主发现。新目标 Nav2 路径验证、daemon 动态目标执行、实际传感器检查和 holdout 物理实验尚未完成。

运行对照要求相同模型、数据、受约束工具、Nav2、Body、预算与独立物理门槛；两组均经过同一 daemon。预注册随机配对、所有失败与重试计入；开发对照另行记录从收到现有 ROS 环境到首次物理验收的工程时间、介入和代码变更。不能用已配置任务运行代替应用开发效率，也不预设 ROSClaw 胜出。

## 10. 当前判断

ROSClaw 胜任本场景已配置、受约束的仿真任务编排。Codex 完成了本次工程搭建和修复，Nav2 完成规划与控制，独立评价器提供物理判据。已有结果支持这项分工；尚无同条件对照证明 ROSClaw 比 Codex 更优。下一步优先安排第三方复现，并按 Challenge 02 的不可变 SIM Body、最新路径/足迹与传感器验收门槛推进新目标执行，再进行公平比较。
