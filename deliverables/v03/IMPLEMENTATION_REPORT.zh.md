## 实现与权限链路

任务只提交一次。测试 Operator 按既定 SIM 策略自动批准每次单目标请求，授权卡和收据留存。真实 Native Agent 读取有界候选目录并以不可变 `proposal_id` 提议单目标动作，Agentd/Operator/rosclawd 校验 SIM Body 后执行。Nav2 控制运动；独立 PhysX、LaserScan、TF 和规范收据组成最终任务证据。没有新增 Agent 内 Runtime，也不允许动态目标工具接受任意 x/y。

在任务输入前，单独编译冻结新的 SIM Body 契约，绑定开发目标集合、初始实测位置、观察者、源文件 SHA256、候选时效、足迹余量及验收规则。原四站权限没有在绑定后被改写。候选来自实际 USD prim 包围盒及地图，朝向已知货架；采用静态占据/未知/边界/连通性/视线筛选。候选目录每 15 墙钟秒刷新，执行前再次验证 90 墙钟秒 / 60 仿真秒时效、源文件和 Body。

daemon 内只读 ROS 助手获取新鲜时钟、TF、AMCL、全局 costmap 与扫描，并调用实际 `ComputePathToPose`。要求规划成功，路径与当前位姿/目标一致。按半地图单元平移、0.05 rad 旋转间隔检查完整 Body 足迹及额外余量，拒绝未知、出界、致命或内切占据。Nav2 动作有独立超时与恢复预算。

到点要求位置误差 ≤0.4 m、朝向误差 ≤0.35 rad、实际停止并稳定停留 ≥2 仿真秒、接触观察完整、零非地面碰撞。增强观测使用实际 `/front_3d_lidar` 扫描端点、map→LiDAR 变换和同时刻独立 PhysX 停止/朝向状态，要求目标已知区域内至少 3 个不同扫描束回波。此证据不证明视觉目标识别、货架身份识别或缺陷检测。展示相机不成为 Agent 的视觉输入。

## 能力评估与下一步

本轮验收谓词固定为“本次起点西侧最近的开发集货架”，不是任意区域自然语言任务。

本阶段证明 ROSClaw 能在准备好的 ROS 机器人环境中，通过受控动态目标完成语义任务编排与证据闭环。新目标来自已知 USD 几何，开发工程仍由 Codex 完成，不证明 ROSClaw 自主开发了这个应用，也没有测量优于 Codex 的时间/成本收益。

同 UID 开发边界、SQLite Memory 和可选 firewall 关闭等条件延续；未验收生产权限隔离、全部安全模块、seekdb 性能或真实硬件。暖缓存启动的可见渲染参数修正经过本阶段实际重置，原间歇启动故障的根因未被严格证明。

现有完整仓库清单进入公开证据，原 8 开发 / 5 holdout 实体分组不能升级为严格未知场景实验。下一阶段须独立准备新布局/目标，先冻结提示词、预算、阈值、种子和分母，再揭示评价目标；同模型工具的任务运行对照与从零任务实现的开发效率对照分别执行。第三方工程师和第二台机器仍未安排，独立实测 **NOT RUN**，复现包与验收步骤已准备。
